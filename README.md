📈 Zerodha Clone — Stock Trading & Market Dashboard

A full-stack clone of the Zerodha trading interface with real-time market data and authenticated dashboard features.

🔹 Features

User authentication (Login & Signup)

Market Watch & Live Price Dashboard

Orders, Holdings & Portfolio pages

Stock charts & candle visuals

Buy / Sell UI workflow

Responsive and minimal UI design

🔹 Tech Stack

Frontend: React, JavaScript, React Router

Backend: Node.js, Express, CORS

API: Zerodha/Kite public APIs for stock data

Communication: REST APIs between frontend & backend

🔹 Highlights

Implemented dashboard similar to Zerodha UI/UX

API integration for real-time & historical stock data

Clean component architecture and reusable UI elements

Secure backend with CORS configuration

🔹 Project Goals

Understand stock trading ecosystem and workflows

Practice full-stack integration with external APIs

Improve dashboard and data visualization skills
